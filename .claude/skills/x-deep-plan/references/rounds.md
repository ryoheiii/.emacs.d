# 明示的なラウンド指定

`s2` / `s3` / `s2o1` / `o1` を指定された場合だけ読む。指定なしの通常計画には適用しない。

| 指定 | 構成 |
|---|---|
| `s2` | Sonnet 2 ラウンド |
| `s3` | Sonnet 3 ラウンド |
| `s2o1` | Sonnet 2 ラウンド + Opus 1 ラウンド |
| `o1` | Opus 1 ラウンド |

Claude Code では各ラウンドで読み取り専用の 3 サブエージェントを並列に使う。
モデルは表の順序に従う。Codex はモデルを切り替えず、同一セッションで同じ回数の
3 観点分析を逐次実行する。指定モデルやツールが使えない場合は制約を報告する。

- 批判: 前提の穴・暗黙の仮定・リスク。
- 実証: 実装の根拠と検証可能性。
- 既存手法との比較: 対象領域で使われる手法との比較。必要な場合だけ外部調査する。

要求・制約・関連ファイルと、前ラウンドの未解決指摘を渡す。
指摘には重要度と根拠を付け、前の指摘を覆す場合はその理由を示す。
成果物は `/tmp/x-deep-plan-<RUN_ID>/` に保存し、計画へ必要な結論だけを統合する。
分析失敗は成功扱いせず、重要な判断の根拠が不足する場合に確認する。
