# コミット規約

すべてのコミットメッセージは Conventional Commits の日本語形式で記述する。

```text
type(scope): 日本語の要約

本文（任意・日本語）
```

`scope` は変更対象が明確になる場合に付け、要約は変更の目的を簡潔に表す。

| type | 用途 |
|---|---|
| `feat` | 新機能 |
| `fix` | バグ修正 |
| `docs` | ドキュメントのみの変更 |
| `style` | コードの意味に影響しない変更（空白、フォーマットなど） |
| `refactor` | バグ修正でも機能追加でもないコード変更 |
| `test` | テストの追加・修正 |
| `chore` | ビルド、CI、依存関係などの雑務 |
| `ci` | CI 設定の変更 |

## コミット分割

- 1 コミットを 1 つの論理的な変更にする。
- 整形、lint、自動生成、import 整理とロジック変更は別コミットに分ける。
- 無関係な修正を便乗させない。
- `Co-Authored-By` トレーラーを付与しない。
